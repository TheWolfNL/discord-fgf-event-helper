Needs Node.js 22 or newer.

```bash
npm install
npm test
```

## Event text and durations

All event templates are in `src/events.ts`: name, description, duration per
part, trade flag (`keep` or `pause`), embed colour and banner file. Edit,
run `npm test`, commit and push; Cloudflare redeploys.

Shadow Front timeslots are `SHADOW_FRONT_SLOTS` in the same file.

## Banners

Banners are generated by `tools/banners/generate.ts` from the artwork in
`tools/banners/art/` and committed to `public/banners/`.

```bash
npm run banners                      # all banners
npm run banners -- arms-race-a       # just one
```

Per theme you can change the gradient colours and where the artwork sits
(`x`, `y`, `width`, `height`) and fades in (`fadeFrom`, `fadeTo`). If you have
a cut-out version of a ship with a transparent background, drop it in
`tools/banners/art/` and point the theme at it.

Banners must stay 1000×400: Discord crops scheduled event covers to 2.5:1.

## Adding an event

1. Add a template to `EVENTS` in `src/events.ts`.
2. Add banner(s) to the `banners` list in `tools/banners/generate.ts` and run
   `npm run banners`.
3. Add a subcommand to `COMMANDS` and a case to `buildAnnouncement` in
   `src/commands.ts`.
4. Push, then re-register the command (see [Updating](updating.md#when-the-commands-change)).

## Running locally

```bash
cp .dev.vars.example .dev.vars   # fill in the values
npm run dev
```

Discord can only reach a public URL, so testing real commands locally needs a
tunnel (for example `cloudflared tunnel --url http://localhost:8787`) set as
the Interactions Endpoint URL of a separate test application.
`npm run register` registers the commands using `.dev.vars`.
